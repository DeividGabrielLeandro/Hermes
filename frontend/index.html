Quem foi Hermes

Filho de Zeus e mensageiro dos deuses, levava recado entre o Olimpo e o mundo dos homens.

O projeto

Um mensageiro entre você e a IA

Crie sua conta, cadastre sua chave de API e converse com a IA por aqui. O hermes guarda o contexto das conversas, para a IA não começar do zero.

Detalhes técnicos no GitHub →

Como usar

Três passos até a primeira mensagem

  1. Crie sua conta

    Cadastro com e-mail e senha.

  2. Adicione sua chave

    Cole a sua chave de API do Gemini nas configurações da conta.

  3. Comece a conversar

    Escreva sua mensagem e o Hermes leva até a IA.

O futuro

Para onde o Hermes vai

  • Mais modelos de IA

  • API própria
